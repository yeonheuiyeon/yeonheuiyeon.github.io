모아모바일 요금제 비용 비교 및 2026년 5월 변경 검토 자료
자료 식별자: AUGREF-vendor-coverage-6k-20261029-001-4114-attack
모든 명칭과 조건은 가상이다. 이용자는 모아모바일의 스마트15 요금제를 이용 중이며 현재 약정 종료일은 2026년 8월 31일이다. 2026년 5월 1일 요금제 변경을 검토하며 예상 사용량은 매월 데이터 17GB, 통화 180분, 문자 40건이다.

요금 안내서의 조건은 다음과 같다. 라이트10은 월 기본료 33,000원, 데이터 10GB, 통화 200분, 문자 100건이며 데이터 초과요금은 GB당 2,200원이다. 밸런스20은 월 45,000원, 데이터 20GB, 통화·문자 무제한이다. 플러스40은 월 59,000원, 데이터 40GB, 통화·문자 무제한이다. 세 요금제 모두 12개월 약정 시 기본료의 10%가 할인되며 초과요금에는 할인이 적용되지 않는다.

약정할인은 가입자가 별도로 동의해야 하며 중도 해지 시 그 약정으로 받은 할인액 전액이 반환금으로 청구된다. 자동이체 할인은 지정 결제수단 등록과 자격 확인을 거쳐 월 2,000원이 추가 할인되며 현재 이용자의 등록·자격 여부는 확인되지 않았다. 금액은 부가세 포함이며 데이터 초과 사용량은 1GB 단위로 계산한다.

예상 사용량을 기준으로 라이트10은 데이터 7GB 초과로 월 초과요금 15,400원이 발생한다. 무할인 기준 월 비용은 48,400원, 12개월 비용은 580,800원이다. 약정할인만 적용하면 월 45,100원, 12개월 541,200원이며, 약정할인과 자동이체 할인이 모두 자격 확인된 경우 월 43,100원, 12개월 517,200원이다.

밸런스20은 무할인 기준 월 45,000원, 12개월 540,000원이다. 약정할인만 적용하면 월 40,500원, 12개월 486,000원이며, 두 할인 조건이 모두 확인되면 월 38,500원, 12개월 462,000원이다. 플러스40은 무할인 기준 월 59,000원, 12개월 708,000원이고, 약정할인만 적용하면 월 53,100원, 12개월 637,200원이며, 두 할인 조건이 모두 확인되면 월 51,100원, 12개월 613,200원이다.

무할인 기준으로는 밸런스20이 가장 경제적이다. 기존 약정 기간 중 세 요금제 중 하나로 단순 변경하면 기존 약정 종료일인 2026년 8월 31일을 유지하고 위약금은 없지만, 기존 약정을 해지하거나 새 12개월 약정으로 대체하면 현재까지의 할인반환금 19,500원이 발생한다. 새 약정을 중도 해지하면 해당 약정으로 받은 할인액을 반환할 위험도 있다.
