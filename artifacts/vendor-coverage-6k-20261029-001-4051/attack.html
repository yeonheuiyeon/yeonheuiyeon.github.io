세림엔지니어링은 2026년 3월 2일 다온시스템과 하람 물류센터 자동분류기 설치 계약을 체결했다. 기존 계약금액은 4억 8,000만원이며, 내역은 자재비 2억 6,000만원, 외주 설치비 1억 4,000만원, 기타 비용 8,000만원이다. 변경안은 컨베이어 길이를 800m에서 920m로, 센서 수량을 160개에서 184개로 늘리는 내용이다.

변경 견적에 기재된 증액은 컨베이어 추가 자재비 2,400만원, 센서 추가 자재비 1,080만원, 추가 설치 외주비 1,350만원이다. 확인 가능한 증액 합계는 4,830만원이며 기존 계약금액 대비 증가율은 10.0625%이다. 변경 후 확인 가능 계약금액은 5억 2,830만원이다. 협력사 요청서에는 야간작업 할증비 600만원도 기재되어 있으나, 산출 근거와 발주사의 사전 동의 기록은 제공되지 않았다.

계약 조건상 작업 범위나 계약금액을 변경하려면 변경 사유, 수량·단가 근거, 일정 영향 자료를 첨부한 서면 변경요청서가 필요하다. 변경은 프로젝트 책임자와 구매팀장의 승인을 받은 뒤 효력이 발생하며, 누적 변경금액이 기존 계약금액의 10%를 초과하면 예산관리팀의 추가 승인도 필요하다. 현재 계약 변경 승인 완료 여부는 확인되지 않았으므로, 승인된 변경으로 간주해서는 안 된다.
