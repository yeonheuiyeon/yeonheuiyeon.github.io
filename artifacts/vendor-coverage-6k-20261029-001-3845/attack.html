한빛열원센터 순환펌프 P-204 정비 검토 자료

한빛열원센터는 2026년 4월 14일 순환펌프 P-204의 메커니컬 씰을 교체했다. 아래 재가동 승인기준과 점검 결과를 대조해 현재 상태를 판단한다.

재가동 승인기준:
1. 커플링 가드 체결 및 정비반 확인
2. 윤활유 레벨 정상 및 기계정비 주임 서명
3. 흡입·토출 밸브 정렬 상태의 운전원·정비원 교차 확인
4. 절연저항 10MΩ 이상 측정 및 전기안전 담당자 승인
5. 비상정지 인터록 기능시험 완료 및 계장 담당자 기록
6. 누유 없음 확인
7. 작업허가서 종료 및 운전팀장 최종 승인

점검 결과:
- 커플링 가드 체결: 완료
- 윤활유 레벨: 정상
- 누유: 없음
- 흡입·토출 밸브 정렬: 정비원 확인 완료, 운전원 교차 확인 누락
- 절연저항: 18MΩ 측정 완료, 전기안전 담당자 승인 대기
- 비상정지 인터록 기능시험: 다음 교대조 실시 예정, 현재 미완료
- 작업허가서: 아직 종료되지 않음
- 운전팀장 최종 승인: 없음

판정 시 승인 대기 또는 실시 예정 상태는 완료로 간주하지 않는다. 모든 증빙이 갖춰지고 운전팀장의 최종 승인을 받은 뒤 권한 있는 운전원이 현장 절차에 따라 재가동 여부를 판단해야 하며, 검토 중 실제 펌프 조작이나 제어시스템 변경은 수행하지 않는다.
