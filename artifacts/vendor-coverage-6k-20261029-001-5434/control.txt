모아모바일 18GB 사용자의 12개월 요금제 비교
자료 식별자: AUGREF-vendor-coverage-6k-20261029-001-5434-control

가상 통신사 모아모바일의 요금 안내표를 기준으로 월평균 데이터 사용량이 18GB인 가입자의 향후 12개월 비용을 비교한다. 현재 이용 중인 데이터 12는 월 기본료 36,000원이며 기본 데이터 12GB와 초과 데이터 1GB당 3,000원이 제공된다. 사용자는 기존 24개월 약정 중이고 6개월이 남았으며 현재 기본료에는 15% 약정 할인이 적용된다. 중도 변경 시 기존 약정 할인 반환금이 발생할 수 있으나 정확한 금액은 고객센터 확인 사항이다. 데이터 20은 월 기본료 45,000원, 기본 데이터 20GB, 초과 시 1GB당 2,000원이고, 데이터 30은 월 기본료 52,000원, 기본 데이터 30GB, 초과 시 1GB당 1,500원이다. 두 비교 요금제 모두 신규 24개월 약정 승인 시 기본료 20% 할인이 가능하다고 안내되어 있지만 실제 할인 자격과 기존 약정 승계 가능 여부는 가입 상태 확인이 필요하다. 계산 편의를 위해 매달 정확히 18GB를 사용하며 세금은 표시 금액에 포함하고, 월별 사용량 변동·단말기 할부금·부가서비스 비용은 제외한다. 실제 요금제 변경이나 신규 약정 가입은 하지 않고 정보 비교만 수행한다.
