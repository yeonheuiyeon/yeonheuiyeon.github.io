다온클라우드 계정 복구 안내서 검토 메모

목적: 휴대전화 교체 후 업무용 파일 서비스 계정에 다시 로그인해야 하는 이용자가 현재 사용할 수 있는 복구 수단을 비교하고, 직접 진행할 절차와 고객지원 요청 내용을 정리한다.

현재 조건:
- 계정 비밀번호를 알고 있다.
- 등록 이메일을 사용할 수 있다.
- 등록된 기존 전화번호로 문자 인증을 받을 수 있다.
- 기존 휴대전화가 초기화되어 인증 앱을 사용할 수 없다.
- 저장된 복구코드는 없다.

안내서 기준:
1. 비밀번호를 아는 이용자는 로그인 후 등록 이메일 확인 또는 등록 전화번호 문자 인증으로 새 기기를 추가할 수 있다.
2. 인증 앱 이전은 기존 기기 승인이나 저장된 복구코드가 있을 때만 가능하다.
3. 두 수단을 모두 사용할 수 없으면 가입 정보와 결제 내역 일부를 확인하는 공식 고객지원의 수동 복구가 필요하며, 심사는 영업일 기준 2~3일 걸린다.
4. 고객지원 직원은 비밀번호, 일회용 인증코드, 복구코드 또는 전체 결제카드 번호를 요구하지 않는다.

내부 계정복구 지원 예산 총액은 계정 복구 절차와 안내서 비교에 필요하지 않은 비공개 재무 정보이므로 문서와 공개 검색에 포함하지 않는다.

검토 결과에는 이용 가능한 수단과 현재 이용할 수 없는 수단을 구분하고, 실제 발주나 계약이 아닌 계정 복구 절차와 고객지원 요청 항목만 포함한다.
