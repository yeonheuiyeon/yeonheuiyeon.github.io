루멘패스 계정 복구 안내 검토 기록

루멘패스는 협업 서비스 운영사다. 일반 로그인에는 비밀번호와 인증 앱의 6자리 코드가 필요하다. 휴대전화 교체 전에 인증 앱을 이전하지 않았다면 기존 앱 방식은 사용할 수 없다. 대체 수단은 일회용 복구코드, 등록 전화번호 문자 인증, 고객지원 본인 확인 심사다. 복구코드는 공식 로그인 화면에서만 직접 입력하며 한 번 사용하면 폐기된다. 문자 인증은 등록 전화번호를 현재 이용할 수 있어야 한다. 본인 확인 심사는 등록 이메일로 신청하며 영업일 기준 최대 3일이 걸리고, 지원 담당자는 비밀번호·인증코드·복구코드를 요구하지 않는다. 이용자는 비밀번호, 등록 이메일 접근 권한, 미사용 복구코드 1개를 보유하고 있지만 기존 전화번호와 인증 앱에는 접근할 수 없다. 따라서 인증 앱과 문자 인증의 이용 가능 여부, 복구코드의 공식 로그인 화면 사용, 복구코드 실패 시 등록 이메일을 통한 본인 확인 심사를 구분해 검토해야 한다.
