발행 부서: 고객지원팀
적용 기준일: 2026년 3월 1일

1. 이용자 사용량 및 현재 요금제
최근 3개월 이용자의 월평균 데이터 사용량은 42GB이다. 현재 이용 중인 ‘라이트 20’은 월 기본료 39,000원이며 기본 데이터 20GB를 제공한다. 기본 데이터 소진 후 초과요금은 1GB당 2,000원이다. 현재 약정 만료일은 2026년 8월 31일이며, 조회 시점에 약정 중도해지 위약금은 48,000원으로 안내된다.

2. 비교 대상 요금제
‘데이터온 30’은 월 기본료 49,000원, 기본 데이터 30GB, 기본 데이터 소진 후 1GB당 2,000원의 초과요금이 적용된다. 12개월 약정 가입 시 월 5,000원의 약정 할인이 제공된다. 가족 회선과 인터넷 서비스가 결합 요건을 충족하면 월 5,000원의 결합 할인을 신청할 수 있다.

‘데이터온 60’은 월 기본료 69,000원, 기본 데이터 60GB를 제공한다. 기본 데이터 소진 후에는 추가 데이터 요금 대신 최대 3Mbps 속도 제한이 적용된다. 24개월 약정 가입 시 월 10,000원의 약정 할인이 제공된다. 가족 회선과 인터넷 서비스가 결합 요건을 충족하면 월 10,000원의 결합 할인을 신청할 수 있다.

3. 할인 및 변경 조건
약정 할인은 약정 기간과 중도해지 조건을 확인한 뒤 적용된다. 결합 할인은 가족 회선과 인터넷 서비스의 가입 상태 및 명의 요건을 추가 확인해야 하며, 현재 적용 여부는 확정되지 않았다. 약정 할인과 결합 할인의 중복 적용 가능 여부는 요금제와 가입 조건에 따라 통신사 확인이 필요하다. 요금제 변경 시 변경 적용일, 기존 약정의 중도해지 위약금, 데이터 제공량의 일할 계산 여부를 확인해야 한다.

4. 이용상 유의사항
요금제 변경 또는 새 약정 가입 전 월평균 사용량과 실제 청구 기준을 확인해야 한다. 데이터온 30은 월 30GB를 초과하면 초과요금이 발생하고, 데이터온 60은 60GB 소진 후 속도 제한이 적용된다. 할인 자격이 확인되지 않은 경우 할인 적용 전후의 비용을 각각 비교해야 하며, 실제 변경이나 가입은 이용자의 동의 후 진행한다.
