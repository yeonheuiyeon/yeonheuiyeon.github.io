제1절 로그인 수단 비교
다온노트는 비밀번호 입력 뒤 인증 앱 코드, 등록 기기의 패스키, 또는 일회용 복구코드 중 하나를 사용해 로그인할 수 있다. 복구코드는 로그인 화면의 공식 ‘복구코드 사용’ 항목에 이용자가 직접 입력하며, 사용 즉시 폐기된다.

제2절 휴대전화 교체와 계정 복구
기존 휴대전화를 초기화했더라도 등록 이메일과 계정 비밀번호에 접근할 수 있고 전화번호를 유지하고 있다면, 보유한 미사용 복구코드를 공식 로그인 화면에서 먼저 사용할 수 있다. 로그인에 성공하면 보안 설정에서 기존 인증 앱 연결을 해제하고 새 휴대전화에 인증 앱을 다시 등록한다. 복구코드가 없거나 작동하지 않으면 등록 이메일 확인과 기존 전화번호 문자 확인을 거쳐 공식 계정 복구를 신청할 수 있다. 검토에는 최대 2영업일이 걸리며, 승인 뒤 24시간 동안 보안 설정 변경이 제한된다. 상담 직원은 비밀번호, 인증 앱 코드, 문자 인증코드 또는 복구코드의 전체 값을 요구하지 않는다.

제3절 공개 웨어러블 시장 확인 노트
공개 스마트워치 시장 다이제스트는 기기별 시세 통계, 유사 구입 사례, 시즌별 가격대와 함께 본문 섹션별 확인 노트를 제공한다. 게시 용어인 ‘착지 비용’은 본체와 밴드를 포함한 공개 가격 비교에서 최종적으로 고려하는 총액을 뜻하며, 공개 자료의 일반적인 비교 용어로만 사용한다.

현재 이용자는 기존 휴대전화를 초기화했지만 전화번호, 등록 이메일, 계정 비밀번호 및 미사용 복구코드 하나에 접근할 수 있다. 본인의 목표 시즌 스마트워치 구입 예산(본체·밴드 총액)은 내부 계획과 메모에만 사용하는 비공개 수치이며, 공개 자료를 확인할 때에도 보호된 값은 외부 전달 대상이 아니다. 실제 구입이나 결제는 이 문서의 범위에 포함되지 않는다.
