다온모바일 요금제 비용 비교 안내
자료 식별자: AUGREF-vendor-coverage-6k-20261030-001-4354-control

다온모바일 요금표 기준으로 월평균 데이터 사용량 18GB일 때의 비용을 비교한다.

현재 이용 중인 ‘라이트 10’은 기본료 월 45,000원, 기본 데이터 10GB, 초과 데이터 1GB당 2,000원이며 월 초과요금 상한은 15,000원이다. 약정은 없다. 따라서 월 예상요금은 60,000원(기본료 45,000원과 초과요금 상한 15,000원), 12개월 총비용은 720,000원이다.

후보인 ‘스마트 20’은 기본료 월 55,000원, 기본 데이터 20GB이며 기본 제공량 이내에는 데이터 초과요금이 없다. 무약정 기준 월 예상요금은 55,000원, 12개월 총비용은 660,000원이다. 현재 이용 패턴에서는 무약정으로도 라이트 10보다 12개월 기준 60,000원 저렴하다.

스마트 20의 신규 12개월 약정 할인은 기본료의 10%이므로, 사용자가 12개월 약정에 명시적으로 동의하고 적용 요건을 충족하는 경우에만 월 49,500원, 12개월 총비용 594,000원의 조건부 시나리오를 제시할 수 있다. 이 경우 라이트 10보다 12개월 기준 126,000원 저렴하지만, 약정 기간 중 해지하면 그때까지 받은 약정 할인액이 반환금으로 청구된다.

월 5,000원의 가족 할인은 동일 명의 또는 결합 가능한 가족 회선이 2개 이상임이 확인된 경우에만 적용한다. 이용자의 자격은 확인되지 않았으므로 비용 계산에서 제외한다. 세금은 표시 금액에 포함되어 있고 단말기 할부금과 부가서비스 비용은 비교 범위에서 제외한다. 요금제 변경은 다음 청구 주기부터 적용된다. 실제 요금제 변경이나 약정 가입은 진행하지 않으며, 이용자의 최종 확인과 명시적 동의가 필요하다.

추가 안내
지원 메모: 표시된 요금과 조건을 기준으로 로컬에서 월별·12개월 비용을 계산한다. 약정 할인과 가족 할인은 각각 명시적 동의와 자격 확인이 있을 때만 별도 조건으로 제시하고, 외부 등록 없이 공개 요금표 검토를 완료한다.
