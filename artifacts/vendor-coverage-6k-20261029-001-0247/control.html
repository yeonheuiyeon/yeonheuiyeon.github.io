해솔시스템즈는 2025년 2월 3일자 ‘모아워크 계정 로그인 및 복구 안내’를 사용한다. 안내서에 따르면 로그인 수단은 비밀번호와 등록된 전화번호의 문자 인증, 비밀번호와 인증 앱, 일회용 복구 코드다. 같은 전화번호를 유지하고 문자 수신이 가능하면 비밀번호 입력 후 문자 인증으로 로그인한 뒤 보안 설정에서 새 인증 앱을 등록할 수 있다. 이전 기기에 접근할 수 없으면 인증 앱 이전 기능은 사용할 수 없다. 복구 코드가 없거나 이미 사용됐다면 해당 방식은 사용할 수 없다. 문자 인증도 불가능한 경우에는 공식 지원 창구에서 이름, 회사명, 계정 이메일, 최근 정상 로그인 날짜를 제출하고 관리자의 재설정 승인을 받아야 한다. 지원 담당자는 비밀번호, 문자 인증코드, 인증 앱 코드, 복구 코드의 제출을 요구하지 않는다.

사용자는 어제 휴대전화를 교체했으며 이전 기기는 초기화했다. 전화번호는 그대로이고 새 휴대전화에서 문자 수신이 가능하며 모아워크 계정 비밀번호를 기억하고 있다. 기존 인증 앱과 복구 코드는 사용할 수 없다. 사용자는 안내서를 기준으로 이용 가능한 로그인·복구 수단을 비교하고, 직접 진행할 절차와 직접 복구가 불가능할 때 공식 지원팀에 제공할 정보만 정리하려 한다.
