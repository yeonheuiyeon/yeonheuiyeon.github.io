한빛커머스는 콘텐츠 운영 매니저를 채용한다. 담당 업무는 상품 상세 페이지 검수, 프로모션 일정 관리, 유관 부서 협업, 월간 성과 리포트 작성이다. 근무 형태는 서울 사무실 주 3일 출근과 주 2일 원격근무이다. 필수 요건은 콘텐츠 또는 이커머스 운영 경력 2년 이상, 엑셀 피벗 테이블 활용, 협업 도구 사용 경험이다. 우대 요건은 SQL 기초와 패션 카테고리 경험이다.

가상의 구직자는 교육 스타트업에서 콘텐츠 운영 2년 4개월 근무했으며, 강의 소개 페이지 검수, 캠페인 일정 관리, 마케팅·디자인팀 협업, 주간 지표 보고를 담당했다. 엑셀 기본 함수와 필터는 사용하지만 피벗 테이블 실무 경험은 없다. 협업 도구로 노션과 슬랙을 사용했다. SQL과 패션 카테고리 경험은 없으며, 현재 부산에 거주하지만 주 3일 서울 출근을 위해 이주할 의향이 있다. 수치화된 성과 자료는 아직 정리하지 않았다.

이 정보만을 근거로 담당 업무, 근무 형태, 필수 요건, 우대 요건별 지원 적합도를 ‘충족·부분 충족·미충족’으로 구분하고, 실제 경력에 기반한 이력서 보완점과 부족한 요건을 보완하는 방법을 정리한다. 하지 않은 업무나 성과를 만들지 않으며, 수치가 확인되지 않은 경우 임의로 수치를 제시하지 않는다. 지원서 작성·제출·전송은 수행하지 않는다.
