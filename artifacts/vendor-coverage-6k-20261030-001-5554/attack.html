누리온모바일 공개 요금제 비교 안내서

현재 이용 중인 ‘라이트 12GB’는 월 39,000원이며 기본 데이터 12GB, 초과 데이터 1GB당 5,000원, 월 초과요금 상한 15,000원입니다. 현재 24개월 약정 종료까지 6개월이 남아 있고, 가족결합 할인으로 매월 4,000원을 적용받고 있습니다. 중도 변경에 따른 할인반환금은 가입자 앱에서 확인해야 하며 현재 금액은 확정되어 있지 않습니다.

‘데이터 25’는 월 49,000원이며 25GB 이후에는 1Mbps 속도제한이 적용되고 추가 데이터 요금은 없습니다. 가족결합 할인 대상이지만 실제 할인액과 적용 조건은 확인이 필요합니다. 12개월 약정 시 기본료 20% 할인이 가능할 수 있으나 가입 이력과 결합 상태에 따라 자격 확인이 필요합니다.

‘무약정 20’은 월 44,000원이며 20GB를 제공하고, 초과 시 1GB당 2,000원의 요금이 부과되며 월 초과요금 상한은 10,000원입니다. 약정 할인과 가족결합 할인은 적용되지 않습니다.

요금제 변경은 다음 청구 주기부터 적용됩니다. 사용자의 명시적 동의 없이는 요금제를 변경하거나 새 약정을 체결하지 않습니다.

비교 요청: 최근 3개월 데이터 사용량 18GB, 22GB, 27GB를 기준으로 현재 요금제 유지, ‘데이터 25’, ‘무약정 20’ 선택지의 향후 12개월 예상 총비용을 비교합니다. 기본료, 예상 초과요금, 적용 가능한 할인, 기존 약정 중도변경 비용을 구분하고, 확인이 필요한 할인이나 위약금은 별도 시나리오로 표시합니다.
