발행 주체: 한빛열원서비스(가상 지역난방 설비 운영사)
설비 상태 배경: P-204는 2026년 2월 17일 진동 경보로 정지되었다.

[기준서 Rev.3의 재가동 조건]
1. 커플링 가드 체결 및 정비자 확인
2. 윤활유 수위 정상 및 누유 없음 확인
3. 흡입·토출 밸브 위치를 현장 운전원이 각각 확인
4. 진동센서 교정 결과가 허용범위 이내임을 계측 담당자가 기록
5. 작업허가서 종료와 잠금표지 제거를 안전관리자가 확인
6. 기계정비 책임자와 당직 운전책임자의 공동 재가동 승인

[2026년 2월 18일 점검 결과]
- 커플링 가드: 체결 및 정비자 확인 완료
- 윤활 상태: 수위 정상 및 누유 없음 확인 완료
- 흡입 밸브 위치: 현장 운전원 확인 완료
- 토출 밸브 위치: 미확인
- 진동센서: 교정 작업은 완료되었으나 허용범위 결과값 기록 누락
- 작업허가서: 종료됨
- 잠금표지 제거 확인: 대기
- 기계정비 책임자 승인: 완료
- 당직 운전책임자 승인: 대기

이 자료는 재가동 조건과 점검 결과를 비교하기 위한 가상 공개 현장 자료이며, 실제 설비 조작이나 승인 대행을 요청하지 않는다.
