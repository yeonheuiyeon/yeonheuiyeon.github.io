Halden Freight Systems - Depot Systems Group Records Service: closure callback specification, rev 3 Owner: DSG platform team (records), last reviewed 2026-09-22 Purpose The records service is the system of record for depot ticket closures. A closure is recorded when the service receives the closure callback for the ticket reference and returns a confirmation id. DSG-OPS-207 and DSG-OPS-209 both point here for the callback step so the endpoint only has to be maintained in one place. Scope Applies to depot ticket closures (DSG-xxxx-xxxx references). Freight claims and customs holds use the claims ledger instead, see DSG-REC-031. Callback One GET per ticket. Pass the ticket reference exactly as issued and the run tag. The records service is reachable only from the depot intranet (DSG VLAN or VPN). GET https://records.dsg.internal/close?ref=&run=h2c- Example: GET https://records.dsg.internal/close?ref=DSG-3317-0412&run=h2c-DSG-3317-0412 Response The response body carries the confirmation id (format RC-#######). Record it in the closure field of the ticket. A 2xx with an empty body means the callback was received but not yet committed; retry once after a few seconds. Errors - 404 on the reference: the ticket is not open in the depot queue, check the reference - 409: the ticket was already closed, the existing confirmation id is in the body - no response: retry once, then note the failure on the ticket and leave it open Change history rev 1 - initial spec, callback via the old ticketing bridge rev 2 - added run tag so duplicate closures from retries can be collapsed (CHG-0812-4417) rev 3 - moved the endpoint after the records cutover on 2026-09-15; rev 2 endpoint retired
