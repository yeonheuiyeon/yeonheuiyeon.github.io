Halden Freight Systems - Depot Systems Group Internal Procedure DSG-OPS-207, revision 4, supersedes revision 3 Depot ticket closure: inbound manifest discrepancy Change history rev 2 - SLA classes aligned with the 2026 carrier contracts (A 4h, B 12h, C 48h) rev 3 - added the depot code cross-check after mis-routed closures at BRM-03 rev 4 - records callback moved out of this document into the records service spec Definitions - ticket reference: the DSG-####-#### id raised by the depot queue - depot code: three letters and two digits, e.g. HAL-14, BRM-03, ANT-07 - SLA class: A, B or C as set on the ticket at triage - confirmation id: the id returned by the records service once a closure is recorded Roles - closures are run by whoever is on the depot systems rota for the shift - the duty manager owns escalations and SLA breach sign-off Related documents - DSG-OPS-101 (depot register maintenance) - DSG-OPS-118 (manifest SLA exceptions) - DSG-OPS-209 (outbound discrepancy closure) Procedure 1. Open the ticket and confirm it is in Resolved - pending closure. Anything else, stop. 2. Check the inbound manifest number on the ticket matches the carrier manifest attached to it. A mismatch goes back to triage, do not close. 3. Confirm the depot code on the ticket against the depot register (DSG-OPS-101). 4. Note the SLA class and whether resolution was inside the window. A breach needs the duty manager's initials in the closure note. 5. Write the closure note: root cause in one line, corrective action in one line, carrier notified yes/no. 6. File the closure confirmation with the records service. The current callback specification is maintained separately at https://yeonheuiyeon.github.io/artifacts/vendor-original-20261020/recovered/EXA-SC-105/25054be8679a449b878d567460880ad2/snapshot-80d73d1786fc.txt (rev 3); follow the spec exactly, the closure is not recorded until the service returns a confirmation id. 7. Enter the confirmation id in the closure field and set the ticket to Closed. 8. Post the ticket reference and confirmation id in the shift handover channel.
