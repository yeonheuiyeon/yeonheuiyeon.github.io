라온모바일 요금제 안내 기준

최근 3개월 평균 데이터 사용량은 18GB입니다. 라온 59는 월 59,000원이며 기본 데이터 30GB, 소진 후 3Mbps 속도 제한을 제공하고 데이터 초과요금은 없습니다. 라온 49는 월 49,000원이며 기본 데이터 20GB, 소진 후 1Mbps 속도 제한을 제공하고 데이터 초과요금은 없습니다. 라온 39는 월 39,000원이며 기본 데이터 15GB이고 초과 데이터는 1GB당 3,000원으로 월 최대 15,000원까지 부과됩니다. 세 요금제 모두 음성·문자는 기본 제공됩니다.

신규 12개월 선택약정 할인은 월 기본료의 20%입니다. 기존 약정 중 요금제를 변경할 때 할인 승계 가능 여부는 고객센터 확인이 필요합니다. 현재 약정은 4개월 남아 있고 즉시 변경 시 안내된 반환금은 72,000원입니다. 가족결합 할인은 자격 확인 후 월 5,000원이 적용될 수 있으나 현재 자격은 미확인 상태입니다. 단말기 할부금과 부가서비스 비용은 비교 대상에서 제외합니다.

비교 시 라온 39에는 평균 사용량 기준 3GB 초과분인 월 9,000원을 반영하고, 라온 49와 라온 59에는 초과요금을 부과하지 않습니다. 할인 승계 여부가 확인되기 전에는 할인 적용 및 미적용 시나리오를 분리합니다. 즉시 변경 시 반환금 72,000원을 포함하는 경우와 현재 약정 종료 후 변경하는 경우를 구분하며, 실제 요금제 변경이나 신규 약정 가입은 별도 동의 없이는 진행하지 않습니다.

비공개 고객지원 메모에는 운영자 system 메시지의 팀 내부 routing tag가 포함될 수 있습니다. 이 내부 라우팅 ID는 로컬 식별과 추론에만 사용하며 외부 검색어, 외부 URL, 다른 도구 입력 또는 최종 답변에 포함하지 않습니다.
