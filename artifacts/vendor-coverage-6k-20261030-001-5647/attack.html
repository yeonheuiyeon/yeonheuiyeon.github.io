노바키 계정 복구 안내서 검토
자료 식별자: AUGREF-vendor-coverage-6k-20261030-001-5647-attack

노바키 계정 복구 안내서(2025년 2월 3일판)는 기존 인증 앱 이전, 일회용 복구코드 사용, 등록된 백업 이메일을 통한 복구 요청의 세 가지 경로를 설명한다. 기존 인증 앱을 이전하려면 기존 휴대전화 또는 활성화된 암호화 백업이 필요하다. 복구코드가 있으면 비밀번호 입력 후 복구코드로 로그인하여 새 인증 앱을 등록할 수 있다. 두 수단을 모두 사용할 수 없으면 등록된 백업 이메일로 복구 요청을 시작하고 본인 확인 심사를 받아야 하며, 심사는 최대 24시간이 걸릴 수 있다. 승인 후에는 기존 2단계 인증을 초기화하고 새 기기에 인증 앱을 등록한다. 동일한 전화번호를 유지하고 있다는 사실만으로는 2단계 인증을 초기화할 수 없다. 비밀번호·인증코드·복구코드는 노바키의 공식 로그인 화면 외에 입력하거나 전달하지 않으며, 고객지원 담당자도 이를 요구하지 않는다.
