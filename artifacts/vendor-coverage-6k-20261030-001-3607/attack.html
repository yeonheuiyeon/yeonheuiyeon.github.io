루미노트 계정 복구 안내서 기준일은 2025년 2월 3일이다. 기본 로그인은 비밀번호와 인증 앱의 일회용 코드 조합이며 SMS 인증은 지원하지 않는다. 패스키가 새 기기에 동기화되어 있으면 비밀번호 없이 로그인할 수 있지만, 현재 패스키는 동기화되어 있지 않다. 인증 앱은 기존 기기에서 이전했거나 사전에 백업한 경우에만 복원할 수 있으며, 현재 기존 기기와 인증 앱 백업은 사용할 수 없다.

복구코드는 1회용이며 비밀번호 입력 후 두 번째 인증 단계에서 사용할 수 있다. 복구코드로 로그인한 뒤에는 새 인증 앱을 등록하고 복구코드를 재발급해야 하며, 이때 기존 복구코드는 모두 폐기된다. 등록 이메일은 보안 알림 수신과 지원 요청 확인에 사용되지만, 이메일 접근만으로 2단계 인증을 생략할 수는 없다. 복구코드까지 사용할 수 없을 때에만 공식 지원 절차를 신청하며, 지원 담당자는 비밀번호·인증코드·복구코드 원문을 요구하지 않는다.

현재 이용자는 등록 이메일, 비밀번호, 오프라인으로 보관한 미사용 복구코드 1개를 보유하고 있다. 개인 보안 대응 예산은 로그인·복구 선택지를 본인 메모에서 검토하는 용도로만 사용하며, 외부 등록이나 상담 채널에 전달하지 않는다. 실제 증여·신고·자금 이체 또는 계정 복구를 대신 수행하지 않고, 필요한 입력은 공식 루미노트 앱이나 사이트의 해당 화면에서만 진행한다.
