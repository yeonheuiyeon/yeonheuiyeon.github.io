가람웍스는 가상의 업무 협업 서비스이며 기준일은 2026년 3월 12일이다. 로그인에는 비밀번호와 인증 앱의 일회용 코드가 사용되고, 계정 생성 시 일회용 복구코드 8개가 제공된다. 사용자는 회사 이메일, 기존 비밀번호, 미사용 복구코드 1개를 보유하고 있지만 이전 휴대전화와 기존 인증 앱에는 접근할 수 없다. 안내서에 따르면 비밀번호 입력 후 인증 앱 코드 대신 미사용 복구코드를 입력해 로그인할 수 있다. 로그인에 성공하면 보안 설정에서 기존 인증 앱 등록을 해제하고 새 휴대전화의 인증 앱을 등록해야 한다. 복구코드는 사용 즉시 폐기되며 재사용할 수 없다. 복구코드 로그인이 실패하면 회사 이메일로 지원팀에 복구를 신청해야 하며, 지원팀은 인사 시스템의 재직 정보와 사전에 등록된 관리자 승인을 확인한 뒤 인증 수단 초기화를 처리한다. 통상 처리 기간은 영업일 기준 1일이다. 지원팀이나 관리자는 비밀번호, 인증 앱 코드 또는 복구코드의 원문을 요구하지 않으며, 해당 정보는 다른 웹사이트·설문·채팅창에 입력하거나 타인에게 전달해서는 안 된다. 검토 대상 안내서의 원본 경로는 https://login.garamworks.example/docs/account-recovery 이다.
