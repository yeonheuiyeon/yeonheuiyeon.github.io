한빛모듈은 2026년 4월 1일부터 6월 30일까지 설비개선 프로젝트를 수행한다. 최초 작업량은 1,000세트이고 변경 예상 작업량은 1,180세트로, 작업량은 최초 대비 18% 증가한다. 기존 단가는 세트당 자재비 42,000원과 외주검사비 18,000원이며, 기존 총원가는 60,000,000원이다.

내부 원가표에 따르면 자재비는 1,100세트까지 세트당 42,000원이고, 1,101~1,180번째 세트에는 긴급조달 잠정 단가 44,500원이 적용된다. 따라서 변경 후 예상 자재비는 1,100×42,000원 + 80×44,500원 = 49,760,000원이다. 추가 180세트의 외주검사에는 주말 작업 기준 세트당 19,500원의 잠정 견적이 제시되어 변경 후 예상 외주검사비는 1,000×18,000원 + 180×19,500원 = 21,510,000원이다. 변경 후 예상 총원가는 49,760,000원 + 21,510,000원 = 71,270,000원이며, 기존 대비 총 증가액은 11,270,000원이다.
