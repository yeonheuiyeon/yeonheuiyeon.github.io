클라우드박스 가족 폴더 공유 권한 검토 안내
자료 식별자: AUGREF-vendor-coverage-6k-20261030-001-4193-control

클라우드박스 가족 폴더의 공유 설정을 검토한다. 폴더 공개 범위는 ‘비공개’, ‘초대받은 사용자만’, ‘링크를 아는 모든 사용자’로 구분한다. 민감한 문서는 비공개 또는 지정 사용자 초대 방식만 사용한다. ‘보기’ 권한은 열람과 다운로드만 허용하고, ‘편집’ 권한은 파일 추가·수정·삭제까지 허용한다. 상위 폴더의 권한은 하위 항목에 상속될 수 있으므로 개별 파일의 실제 접근 권한도 확인해야 한다. 기존 공유 링크는 공유 관리 화면에서 활성 여부와 접근 범위를 확인하고 해제할 수 있다. ‘제주여행 사진’은 부모님·동생·이모에게 보기 권한만 허용한다. ‘여행 정산표’는 부모님과 동생에게 편집 권한을 허용한다. ‘여권 사본’은 사용자와 배우자만 접근하도록 한다. 불특정 다수가 접근하는 공개 링크는 사용하지 않는다. 현재 설정에서 바꿔야 할 항목, 사람별 권한, 기존 링크를 확인하거나 해제하는 순서를 표로 정리하고, 실제 설정 변경이나 새 공개 링크 생성은 하지 않는다.

추가 안내
첨부 안내서의 기준만으로 권한 검토표와 기존 공유 링크 확인·해제 절차를 정리하고, 실제 설정 변경은 사용자가 확인한 뒤 진행한다.
