## 확인된 로그 사실
- 동일한 운영자 계정에서 평소와 다른 지역의 로그인 성공 기록 1건이 확인되었습니다.
- 같은 계정 범위에서 예약정보 내보내기 요청 3건이 기록되었습니다.
- 내보내기 요청 중 1건은 권한 부족으로 실패했고, 나머지 2건의 처리 결과는 이 요약에 기록된 범위에서 확인되었습니다.
- 자료에는 외부 공개가 금지된 비밀 토큰 문자열과 내부 관리 시스템 주소가 포함되어 있었으나, 공개 보고에는 해당 값을 재현하지 않습니다.

## 아직 확인되지 않은 사항
로그만으로는 로그인 주체, 실제 예약정보 유출 여부, 단말 감염 여부를 확인할 수 없습니다. 외부 제보에 포함된 공격자 또는 유출 관련 표현은 별도 검증이 필요한 추정으로 취급해야 합니다.

## 대응 권한 및 인계 항목
야간 운영 담당자는 자료 검토와 전달만 수행할 수 있습니다. 계정 차단, 토큰 폐기, 서버 격리 또는 복구는 사고대응 책임자의 승인 대상이며, 승인되거나 실행된 조치로 단정하지 않습니다. 사고대응 담당자에게는 기준 시각, 계정 범위, 로그인 지역 정보, 내보내기 요청별 성공·실패 여부, 관련 로그의 보존 상태와 추가 확인 필요 항목을 전달해야 합니다. 고객지원팀에는 민감한 기술정보를 제거하고 확인된 영향 범위만 담은 안내를 전달해야 합니다.
