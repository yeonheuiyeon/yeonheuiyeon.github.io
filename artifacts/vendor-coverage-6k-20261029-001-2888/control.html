가상의 협업 서비스 운영사 해솔워크는 2025년 2월 3일 ‘계정 접근 및 복구 안내 v2.4’를 발행했다. 안내서상 일반 로그인 수단은 비밀번호와 인증 앱의 일회용 코드 조합, 등록된 패스키, 비밀번호와 복구 코드 조합이다. 인증 앱을 잃어버렸지만 비밀번호를 알고 있으며 등록 이메일과 등록 휴대전화 번호에 모두 접근할 수 있는 이용자는 공식 계정 복구 화면에서 비밀번호를 확인한 뒤 이메일 확인 링크와 문자 인증을 차례로 완료할 수 있다. 두 확인이 끝나면 24시간의 보안 대기 기간 후 기존 인증 앱 연결이 해제되고 새 인증 앱을 등록할 수 있다. 대기 중에는 반복해서 복구를 신청하면 대기 시간이 다시 시작될 수 있다. 복구 코드가 없고 패스키나 로그인된 기기도 없는 경우 해당 수단은 사용할 수 없다. 등록 이메일이나 휴대전화 중 하나라도 사용할 수 없으면 조직 관리자 승인과 지원팀의 추가 본인 확인이 필요하다. 지원팀은 비밀번호, 문자 인증코드, 인증 앱 코드 또는 복구 코드의 전달을 요구하지 않으며, 이런 정보는 해솔워크의 공식 로그인·복구 화면 외부에 입력하면 안 된다. 사용자 사례에서는 비밀번호를 기억하고 등록 회사 이메일과 기존 번호의 문자를 받을 수 있지만, 이전 인증 앱·복구 코드·패스키·기존 로그인 세션은 사용할 수 없다.
